RAG and model integrations, tests, and operational scripts.

[`../docs/README_CODE_HANDOFF.md`](../docs/README_CODE_HANDOFF.md). It links to the
architecture, complete module reference, data flows, and operations/testing

- `README_APP_DESCRIPTION.md` — product-level description.
